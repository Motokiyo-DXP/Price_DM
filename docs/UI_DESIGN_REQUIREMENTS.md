# UIデザイン改善要件

- 作成日: 2026-08-08
- 状態: 要件確定・実装中
- 対象: ホーム画面を中心とする利用者向けUI

## 1. 目的

カードの検索と価格登録を迷わず行える、シンプルでスタイリッシュな画面へ改善する。
特にスマートフォンでは、最初に表示される範囲から検索と主要操作へ進みやすくする。

## 2. 確定したデザイン方針

- 「価格の動きを、ひと目で。」という見出しは削除する。
- 基本背景を `#191c1f`、基本文字を `#ffffff` とし、グレーを境界線や補助情報に使用する。
- デュエル・マスターズを想起させる青と黄色をアクセントカラーとして使用する。
- 公式の画像、ロゴ、カードデザインを模倣せず、色の印象だけを参考にする。
- 現在の紫を中心とした配色は廃止し、青を主要操作、黄色を注目箇所に割り当てる。
- 装飾を増やすのではなく、余白、文字の強弱、ボタンの大きさで情報の優先順位を示す。

### 色の役割

| 役割 | 色 | 使用例 |
| --- | --- | --- |
| 基本背景 | `#191c1f` | ページ背景 |
| 基本文字 | `#ffffff` | 見出し、カード名、価格 |
| 主要アクセント | 青 | 「このカードを登録」、リンク、選択状態、フォーカス |
| 補助アクセント | 黄色 | お気に入り、注目表示、小さな強調 |
| 境界・補助情報 | グレー | 枠線、区切り、更新日、件数 |

正確なカラーコードはワイヤーフレームまたは実装プレビューを比較して決定する。黄色の上には原則として黒い文字を使用し、青いボタン上の白文字を含め、十分なコントラストを確保する。

## 3. 情報設計

### ヘッダー

- サービス名には提供されたアウトライン済みSVGロゴを使用する。
- ヘッダー全体の価格登録ボタンは設置しない。
- ヘッダー右側には管理者ページへの控えめなリンクを置く。
- ロゴの代替テキストと管理者リンクのフォーカス表示を用意する。

### ホーム画面上部

- 大きなキャッチコピー領域をなくし、検索欄をより上へ移動する。
- 「みんなで共有するカード相場」と「販売・買取価格と在庫状況を確認できます。」は表示しない。
- スマートフォンの最初の表示範囲に、検索欄またはその大部分が入ることを目標とする。
- サービス名の直下にTCG切替タブを配置する。

### 検索・絞り込み

- カード名検索を最も重要な入力として明確にする。
- 「ざっくり検索」と「パーペキ検索」を検索欄の直下に常時表示する。
- 検索ボタンと絞り込み操作の関係を整理し、狭い画面でも操作が分断されないようにする。
- DMMマイカの、検索と絞り込みが近くコンパクトにまとまっている点を参考にする。
- DMMマイカの画面、素材、配色をそのまま複製しない。

### カードパネル

表示の優先順位を次の順にする。

1. カード名
2. 販売価格・買取価格
3. そのカードの価格を登録する操作
4. 詳細表示、お気に入り、収録情報、更新日などの補助情報

- 各カードパネルに「このカードを登録」ボタンを設置する。
- カードパネル内にはTCG名を繰り返し表示しない。
- 詳細を見る操作と価格登録操作を混同しない見た目にする。
- 青を価格登録の主要ボタンに使用し、黄色はお気に入りなど限定された強調に使用する。
- PCでは一覧性、スマートフォンでは文字とボタンの押しやすさを優先する。

## 4. カード別価格登録の動作要件

- カードパネルの登録ボタンを押すと、価格登録画面へ移動する。
- 移動先では、押したカードがあらかじめ選択された状態にする。
- 同名カードや表記揺れによる誤選択を避けるため、カード名だけではなく安定したカードIDを受け渡す。
- URLは `/register?cardId=<カードID>` のような形式を基本案とする。
- 登録画面には選択済みのカード名を明示し、利用者が必要に応じて別のカードへ変更できるようにする。
- 存在しない、または無効なカードIDの場合は登録を継続せず、カードを選び直せる安全な状態を表示する。

## 5. レスポンシブ要件

### スマートフォン

- 主な対象幅は360〜430pxとする。
- 横スクロールを発生させない。
- タップ対象は十分な高さと間隔を確保する。
- 長いカード名でも価格と登録ボタンが押し出されすぎないようにする。
- 大きな説明領域を避け、検索とカード一覧へ早く到達できるようにする。

### PC

- 複数列のカード一覧を維持しつつ、各カード内の操作位置を統一する。
- 主要コンテンツの最大幅と左右余白を揃える。
- 「このカードを登録」を各カードの同じ位置へ配置する。

## 6. アクセシビリティと操作性

- 色だけで状態や操作の違いを伝えない。
- キーボード操作時のフォーカスを見えるようにする。
- ボタン、リンク、入力欄には内容が分かるラベルを付ける。
- 青、黄色、白、黒の組み合わせは、文字と背景のコントラストを確認する。
- 読み込み中、検索結果なし、エラー時にも次の操作が分かる表示を用意する。

## 7. 今回の範囲外

- カード画像を新たに表示すること。
- DMMマイカと同じナビゲーションや機能を追加すること。
- 管理者画面全体の再設計。
- データベース構造やSupabase認証方式の変更。
- 新機能を伴う大規模な画面構成変更。

## 8. 受け入れ条件

- ホーム画面から「価格の動きを、ひと目で。」が削除されている。
- `#191c1f` と白を基調とし、青と黄色の役割が一貫している。
- ヘッダーに価格登録ボタンがなく、管理者ページが控えめに表示されている。
- 検索欄直下で「ざっくり検索」と「パーペキ検索」を切り替えられる。
- 検索結果のすべてのカードパネルから、そのカードを指定して価格登録画面へ移動できる。
- 移動先で正しいカードが選択済みになっている。
- PCとスマートフォンの両方で、検索、詳細表示、価格登録の既存機能が利用できる。
- キーボード操作、フォーカス表示、文字コントラストに重大な問題がない。

## 9. 実装順序

1. PC版・スマートフォン版の簡易ワイヤーフレームを作る。
2. 青・黄色を含むカラートークンと文字・余白の基準を決める。
3. ヘッダーとホーム画面上部を整理する。
4. カードパネルにカード指定済み価格登録導線を追加する。
5. プレビュー環境でPC・スマートフォンを確認する。
6. 検索、詳細、価格登録、お気に入りの回帰確認を行う。
