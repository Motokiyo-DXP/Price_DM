# カード検索・デッキ統合リリース

- ベース: `5bc2f426004ed497682d76a408a8fa8a567fb2c4`（price-dm/main）。
- `/card-search`: 既存DeckEditorのカード検索・絞り込み・カード表示を閲覧専用で再利用。画面の残り高さを一覧に割り当て、ページ全体のスクロールを止め、一覧内だけを縦スクロールする。
- `/decks`: マイデッキ／デッキ検索のタブ。History APIとhiddenパネルで検索・並び順を保持。未ログインのマイデッキにはログイン案内を表示。
- `/deck-search`: share等のクエリを保持して公開検索タブへ誘導。共有OGPは旧URLと統合URLの両方で同一処理を利用。
- 下部ナビの先頭2項目の名前・リンクのみ変更し、全アイコンを維持。公開デッキの外形・画像・横並びアイコン操作は既存マイデッキのCSSを再利用。

## 既存機能・境界

最新mainの種族・レアリティ・パワー・テキスト検索、検索結果マッピング、編集時の並び順保存、サムネイルのページング、拡大画像、共有権限を保持する。元の作業ツリーにあった登録画面・IME・レイアウトなどの未コミット作業は取り込んでいない。

DBマイグレーション、データ更新、依存関係やCI設定の変更はない。公開デッキの編集は従来どおり自分のコピーを作る操作であり、他人のデッキを直接更新しない。

## ロールバック・検証限界

アプリのみの変更のため、問題時はこのPRをrevertして通常の本番デプロイを行う。DBの巻き戻しは不要。

本番データを作る保存・取り込み・並び替え・削除は動作確認として実行しない。実機でのタッチ／IMEと実SNSクライアントは未検証。ローカルで実画像のファイルがない場合は既存の代替画像になる。
