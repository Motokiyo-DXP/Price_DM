# プロジェクト状況

最終更新: 2026-07-18

## 現在の区切り

カード名単位の相場一覧とカード詳細画面は `main` へマージし、本番反映済みです。

日次平均価格の推移グラフと履歴0件・1日分の表示は `main` へマージし、本番反映済みです。

注意属性を販売最安値・買取最高値から除外する画面フィルターは `main` へマージし、本番反映済みです。

機能ブランチ `motokiyo/store-candidate-foundation` では、承認済み店舗マスターと店舗追加候補を分離するDB基盤を作成中です。本番Supabaseにはまだ適用していません。

本番Supabaseには `canonical_market_details` マイグレーションを適用済みです。ローカルの対応ファイルは次です。

```text
supabase/migrations/20260717182317_canonical_market_details.sql
```

このマイグレーションで追加した参照用ビューとRPCを、一覧とカード詳細画面から利用しています。SupabaseのTypeScript型も本番DBから再生成済みです。

- 公開URLへの自動デプロイ
- カード名の日本語正規化検索

- 全角・半角の価格入力正規化と数字以外の除外
- 登録PINの14日間セッション
- 傷あり、特価、ストレージ、特価ストレージ等の価格属性
- 気になるカードの端末内保存
- 上昇を赤、下落を青、30日超の情報を灰色で表示する基礎
- 登録PINで保護した価格登録
- 公開DB権限の最小化
- カード名単位の現在平均を使った相場一覧
- `/cards/[id]`のカード詳細画面
- 販売最安値、買取最高値、最近の価格記録の表示
- 収録版価格フォールバック時の注意表示
- 日次平均価格の推移グラフと履歴の空状態
- 注意属性を除外した最安値・最高値検索

## DB実装中・画面未実装（機能ブランチ）

- 承認済み店舗マスターの地域・住所・緯度経度の受け皿
- PIN認証済みセッションからの店舗候補受付
- 店舗候補の重複防止、管理者による承認・却下

対応する未適用マイグレーションは次です。

```text
supabase/migrations/20260718044041_store_candidate_foundation.sql
```

現在の本番データは価格記録2件で、いずれも収録版指定ありです。そのため、指定なし価格による平均履歴はまだ空です。画面ではフォールバック価格として注意付きで表示します。

## 既知の開発環境上の注意

一部の外付けSSD環境ではNext.jsの本番ビルド時に`EISDIR/readlink`が発生することがあります。型チェックはSSD上で行い、本番ビルドだけ内蔵NTFSドライブのCloneで確認するか、Vercelのビルド結果を確認してください。
