# プロジェクト状況

最終更新: 2026-07-18

## 現在の区切り

サイト制作は、カード詳細画面の実装前で一時停止しています。

本番Supabaseには `canonical_market_details` マイグレーションを適用済みです。ローカルの対応ファイルは次です。

```text
supabase/migrations/20260717182317_canonical_market_details.sql
```

このマイグレーションで追加したDB機能はまだ画面から利用していません。再開時は、Supabase型の再生成とカード詳細画面の実装から始めます。

## 実装済み

- Next.js / Supabase / Vercelの基本構成
- 公開URLへの自動デプロイ
- カード名の日本語正規化検索
- ざっくり検索（既定）とパーペキ検索
- カード名入力とサジェストの統合
- 同名カードを`canonical_cards`でまとめ、収録版を`card_prints`で分離
- 収録版を指定しない価格登録
- 全角・半角の価格入力正規化と数字以外の除外
- 登録PINの14日間セッション
- 傷あり、特価、ストレージ、特価ストレージ等の価格属性
- 気になるカードの端末内保存
- 上昇を赤、下落を青、30日超の情報を灰色で表示する基礎
- 登録PINで保護した価格登録
- 公開DB権限の最小化

## DB追加済み・画面未実装

- カード名単位の現在平均
- 収録版指定なし価格を優先した平均
- 指定なし価格がない場合の収録版価格フォールバック判定
- 日次平均価格履歴
- 販売最安値の店舗
- 買取最高値の店舗
- 注意属性を除外した最安値・最高値検索
- カードごとの最近の価格記録

現在の本番データは価格記録2件で、いずれも収録版指定ありです。そのため、指定なし価格による平均履歴はまだ空です。画面ではフォールバック価格として注意付きで表示する設計です。

## 既知の開発環境上の注意

一部の外付けSSD環境ではNext.jsの本番ビルド時に`EISDIR/readlink`が発生することがあります。型チェックはSSD上で行い、本番ビルドだけ内蔵NTFSドライブのCloneで確認するか、Vercelのビルド結果を確認してください。
