# 対戦盤面の操作仕様

ステータス: 実装基盤。最終更新: 2026-08-29

## 基本方針

- 紙の対戦と同様に、カードのドラッグを主要な操作の起点にする。
- ルールエンジンが勝手にターン進行やドローを行わない。各ターンの強制ドローは実装しない。
- カード能力を完全自動化せず、頻出操作をショートカットとして提供する。
- マウス、タッチ、キーボードのいずれでも同じ結果へ到達できるようにする。

## ジェスチャーの優先順位

同じカードに対する操作が競合しないよう、次の順で確定する。

1. ポインター移動が8pxを超えたらドラッグとして確定する。
2. 移動せず500ms経過したら長押しとして確定し、詳細を表示する。
3. 250ms以内に離し、移動が8px以下ならタッチとして確定し、タップ状態を切り替える。
4. マウスのダブルクリックは操作メニューを開く。直前の単クリックによるタップ切替は取り消す。

ドラッグ中、長押し成立後、操作メニュー表示中はタップ切替を発生させない。タッチ端末の
ダブルタップは拡大操作と競合するため、初期版では操作メニュー用の「…」ボタンも併設する。

キーボード操作は Enter で操作メニュー、Space でタップ切替、矢印キーと移動メニューで
ゾーン移動を提供する。

## ゾーンと表裏

移動後の既定状態は移動先を基準とする。

| 移動先 | 既定状態 |
|---|---|
| 山札 | 裏向き |
| シールド | 裏向き |
| 手札 | 所有者にのみ表向き |
| マナ | 表向き |
| バトルゾーン | 表向き |
| 墓地 | 表向き |
| 超次元・GR・公開領域 | 表向き |

操作メニューから既定値を上書きできる。相手の非公開カードIDはクライアントへ送らず、
「裏向きカードと枚数」だけを相手用の盤面データへ含める。

## シールドへ追加したカードの印

対戦開始時の初期シールドには印を付けない。対戦中に裏向きでシールドへ置いたカードには、
カード内容を明かさない追加順マーカーを付ける。

- 表示例: `追加1`、`追加2`
- マーカーはそのカードがシールドを離れた時点で削除する。
- 相手にもマーカーは見せるが、移動元やカードIDは見せない。
- 操作履歴には実際の移動元を保存する。

## 山札の操作メニュー

山札のダブルクリックまたは「…」から次を表示する。

- シャッフル
- 上から見る
- 上から指定枚数を表向きにする
- 上から指定枚数を墓地へ置く
- 山札内を検索する
- 山札下へ送る
- ヨビニオン
- メクレイド

ヨビニオンとメクレイドはカード固有処理としてハードコードせず、共通の「上から公開し、
条件一致を選び、残りを指定順に戻す」操作へパラメーターを渡す。コスト、文明、カードタイプ、
公開上限、移動先を指定可能にする。

## 一人回しの視点切替

盤面上部に「視点を入れ替える」ボタンを配置する。切替では盤面の所有権やターンを変更せず、
表示するプレイヤーと非公開情報の閲覧権限だけを切り替える。オンライン対戦ではこのボタンを
表示しない。

## マナ支払いフロー

1. 未タップのマナをタップすると支払いモードを開始する。
2. 追加のマナをタップ・解除して支払い候補を調整する。
3. 支払いモード中は、手札からプレイ領域へのドラッグだけを主要操作として受け付ける。
4. ツインパクトなら使用する面を選択する。
5. 選択マナの枚数と文明が、選択面のコスト・文明を満たすか確認する。
6. 不足時はカードを手札へ戻し、不足数・不足文明を表示する。マナ選択は維持する。
7. 充足時は「召喚」「呪文を唱える」などの形式を確認する。
8. 確定後に一つの操作としてイベント履歴へ保存する。

支払いモードには常にキャンセルを用意し、キャンセル時は今回の支払い操作でタップしたマナを
元へ戻す。効果によるコスト増減・軽減は、確認画面で最終コストを手動調整できるようにする。
