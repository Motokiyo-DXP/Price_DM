# デュエル・マスターズ公式カード情報の取扱い

## 現在の方針

2026-07-25、プロジェクト管理者から公式カード情報の利用許諾を取得した旨の確認を受け、
全件取込の準備と取得を開始した。

実際の公開・継続更新は、許諾回答に記載された対象項目、クレジット表記、更新頻度、
公開範囲などの個別条件を優先する。条件が判明した場合は、この文書と実装へ反映する。

## 取得・保存する項目

- カード名
- 公式カードID
- 収録番号
- 商品名
- 公式カード詳細URL
- カード名から生成した検索用の機械読み

画像、カード本文、フレーバーテキスト、価格は取得・保存しない。
機械読みは公式情報として扱わず、`source = 'generated'`、`verified = false` とする。

第三者サービス由来の別名・読みは、今回の公式許諾による取込には含めない。

## 取得時の安全策

- 公式サイトの `robots.txt` を先に確認する。
- リクエスト間隔は1件につき1秒以上とする。
- HTTP 403、429、5xxでは安全に停止する。
- 取得状態を `.local` のチェックポイントへ保存し、途中から再開可能にする。
- 取得物と生成SQLはGitへ含めない。

## 投入時の安全策

- 現行の `canonical_cards`、`card_prints`、`card_search_terms` へ投入する。
- 100件単位のトランザクションに分割する。
- 公式カードIDを使って冪等にUpsertする。
- `manually_locked = true` のカード・収録版は自動更新しない。
- 既存データを一括削除しない。
- 全件取得完了、件数一致、重複0件、失敗0件、禁止項目0件を確認してから投入する。
- 各チャンク適用後に件数を検証し、異常時は後続チャンクを停止する。
- 本番適用ランナーは、全件取得済みマニフェスト、リンク済みプロジェクトrefとの一致、
  `--confirm-production` の明示指定が揃わなければ実行しない。
- 適用済みチャンクは `.local/dm-import-apply-checkpoint.json` へ記録し、中断時は
  未適用チャンクから再開する。
